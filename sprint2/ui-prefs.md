### Platform
- web based, works for all platform, mobile and desktop

### User UI
- change over time for various health scores/variables
- more graphical the data the better, trends and tendencies over time
- user can see their data in comparison to broad group
- dashboard with forms that are menu driven, radio buttons, checkboxes
- reminders and/or todo list for tasks
- user has straightforward format, mostly click and point

### Researcher UI
- tool allows researcher to add more data to reports
- researcher has menu of how to look at data, case wise, group wise, different variables

### Healthcare Provider
- providers can see data relevant to their patients
